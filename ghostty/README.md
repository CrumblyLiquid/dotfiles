# Ghostty

This is a basic ghostty configuration.

## Format

Ghostty uses a custom INI-like syntax.
Each line is a `key = value` pair.
Lines starting with `#` are comments.

## Location

Ghostty reads from `~/.config/ghostty/config.ghostty`.

## Shaders

Shaders are stored under `shaders/`.

I use a custom shader for the cursor warp effect.

## Sources

See the [Ghostty documentation](https://ghostty.org/docs/config) for more information.
